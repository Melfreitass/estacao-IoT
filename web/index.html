Monitoramento em tempo real

01

Sobre o projeto

🎯

Objetivo

Criar uma estação capaz de coletar dados do ambiente e enviá-los em tempo real para um dashboard web.

⚙️

Hardware

ESP32, sensor DHT11, sensor MQ-135 e LEDs para indicação de situações de alerta.

📡

Comunicação

Os dados são enviados através do protocolo MQTT utilizando o broker Mosquitto.
